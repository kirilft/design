# Copy: English

Apply these rules to visible English copy, including headings, labels, and buttons.

- Use curly apostrophes for contractions and possession (don’t, the designer’s brief) and curly quotation marks for quotations (“Save changes”).
- Use an em dash (—) with no spaces for a break in a sentence, an en dash (–) with no spaces for a range (2024–2026), and a hyphen (-) for compound words (full-width).
- Leave no spaces around slashes in short labels and values (Light/Dark, 24/7).
- Format times consistently for the locale. In 24-hour time, use a colon with no spaces (09:30). Use an en dash for a compact time range (09:30–17:00).
- Use one space between sentences. Place no space before a comma, period, colon, or question mark.
