# Components

- Build components for every repeated UI element: Header, Footer, Container, Button, Card, Input.
- Law of similarity: the same function always looks the same. A different function looks different.
- Every component has a Light and a Dark variant.
- Interactive components have these states: default, hover, pressed, focus, disabled.
- Corners follow [layout.md](layout.md).

## Icons
Use the default icon family of the platform:
- iOS/macOS app: SF Symbols (licensed for Apple platforms only)
- Android app or website: Material Symbols
- Multiplatform app: Font Awesome

Use one icon family per project, with one stroke weight. Size icons to the text next to them.
