# Design Rules

These rules are mandatory. Do not break them. If a rule needs a decision (color, fonts), ask the user and offer a sensible default. Only ask about meaningful changes. Group questions and ask them together.

First check the platform: website or app (iOS, Android, desktop). The rules are written for websites. In an app, apply the same rule with the platform's equivalent (pt/dp instead of rem, native components instead of HTML). Skip rules that only exist on the web.
